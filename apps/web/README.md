# AI Studio 前端

React、TypeScript、Vite 中文品牌素材工作台。所有产物均明确标注为本地模拟演示，不调用真实模型或付费服务。

## 运行

在 `apps/web/` 目录执行：

```sh
npm install
npm run dev
```

开发地址为 `http://127.0.0.1:5173`；API 默认连接 `http://localhost:4000`。后端 CORS 需允许前端来源。部署时可使用 `.env.local` 或构建环境配置：

```env
VITE_API_BASE_URL=http://localhost:4000
```

此配置在构建时注入，修改后需重启开发服务或重新构建。不要在 `VITE_*` 中写入凭据。

```sh
npm run test
npm run build
npm run preview
```

构建产物位于 `dist/`，预览地址为 `http://127.0.0.1:4173`。如使用 AgentsRoom，长驻开发服务应通过开发命令面板启动。

## 行为

- 按 `docs/implementation-brief.md` 契约加载模板、历史及运行详情；视频、编码入口常驻并禁用。
- 描述去除首尾空白，长度 1–2000 字符；数量为 1–8 的整数。
- 提交时锁定请求；结果不确定时，相同输入重试沿用幂等键；成功后的新创作使用新键。
- 活跃运行每 2 秒刷新，闲置每 10 秒刷新；错误时逐步退避至 30 秒；页面隐藏时暂停，恢复时立即刷新。切换运行、重新连接和卸载时清理定时器与请求。
- 请求超时为 12 秒；离线时展示恢复按钮。运行失败支持重试失败节点，排队及运行中支持取消。
- 素材由 API 提供，支持预览和 Blob 下载；资产地址仅接受 HTTP(S)。预览窗口支持 Escape、焦点限制及关闭后返回焦点。
- 不自动补造成功运行或素材。API 未启动时保留完整界面，清楚提示服务未连接。

## 验证与边界

`npm test` 覆盖输入、错误与数据契约、幂等提交、重复提交防护、轮询清理、禁用入口、创建/取消/重试交互，以及素材预览/下载与下载错误恢复。`npm run build` 执行严格 TypeScript 检查和生产构建。

当前没有真实模型、上传、视频生成、编码沙箱、鉴权或计费。模拟费用为零。下载依赖 API 可用及正确 CORS；浏览器与实际后端的集成验收由协调者执行。
